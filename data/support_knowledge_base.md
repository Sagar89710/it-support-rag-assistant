# IT Support Knowledge Base

## Password Reset
Employees can reset a forgotten password from the company identity portal. Select **Forgot password**, verify the registered mobile number, and follow the reset link. Passwords must be at least 12 characters and must not reuse the previous five passwords.

## VPN Access
To connect to the corporate VPN, install the approved VPN client, sign in with company credentials, and complete multi-factor authentication. If access fails, confirm that the device date and time are correct and that the account is not locked.

## Laptop Hardware Issues
For a laptop that does not start, connect the charger, remove external devices, and hold the power button for 10 seconds. If the device still does not start, open a hardware support ticket with the asset number and a description of the symptoms.

## Software Installation
Employees must request software through the internal software catalog. Applications that process company data require security approval before installation. Do not install unapproved software on managed devices.

## Incident Escalation
Escalate incidents when there is a suspected security event, repeated service failure, data loss, or an issue affecting multiple users. Include timestamps, screenshots, error messages, affected service, and steps already attempted.
